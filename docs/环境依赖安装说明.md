# 环境依赖安装说明

## VC++ 运行库

CapsWriter-Offline 依赖 VC++ 运行库。如果启动时提示缺少 DLL，说明系统未安装。

**下载安装**：<https://aka.ms/vs/17/release/vc_redist.x64.exe>

直接下载安装即可，一般安装一次后系统里的所有程序都能用。


## FFmpeg

文件转录功能需要调用 `ffmpeg` 来提取音视频文件的音频流。

安装方式：

1. 访问 <https://ffmpeg.org/download.html>，点击 Windows 下的图标
2. 推荐从 **gyan.dev** 下载：<https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-full.7z>
3. 解压后，将 `ffmpeg/bin` 文件夹路径添加到系统 PATH 环境变量中


## Apple Silicon

只支持 M 系列。Intel Mac 不跑 MLX。

1. 安装 Python 3.12 或 3.13（仓库要求仍是 `>=3.14`，但 MLX 若还没有 cp314 的 arm64 轮子，Mac 上先用有轮子的版本）。再装 [ffmpeg](https://ffmpeg.org/download.html)，`brew install ffmpeg` 即可。
2. 在仓库根目录执行 `pip install -r requirements-macos.txt`。不要安装 `onnxruntime-directml`、`pywin32`、`keyboard`。
3. 把 MLX 权重放到 `models/mlx/`，目录名是 `SenseVoiceSmall`、`Fun-ASR-Nano-2512`、`Qwen3-ASR-1.7B-8bit`、`Qwen3-ASR-0.6B-8bit`、`Qwen3-ForcedAligner-0.6B-8bit`。缺目录时启动会写出目录名。需要下载时把 `config_server.py` 的 `mlx_auto_download` 设为 True，或调用 `core.server.engines.mlx.download.download_all`。
4. 系统设置里打开麦克风、辅助功能和输入监控。没有麦克风权限时会提示去系统设置，进程不退出。没有辅助功能权限时文字留在提示里，不上屏。
5. 听写默认按住右 Option。这个键按不住时，改 `config_client.py` 的 `darwin_shortcuts`，例如改成 `f8`，不要改回 CapsLock。
