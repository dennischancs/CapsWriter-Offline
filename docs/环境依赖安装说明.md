# 环境依赖安装说明

## VC++ 运行库

CapsWriter-Offline 依赖 VC++ 运行库。如果启动时提示缺少 DLL，说明系统未安装。

**下载安装**：<https://aka.ms/vs/17/release/vc_redist.x64.exe>

直接下载安装即可，一般安装一次后系统里的所有程序都能用。


## FFmpeg

文件转录功能需要调用 `ffmpeg` 来提取音视频文件的音频流。

安装方式：

1. 访问 <https://ffmpeg.org/download.html>，点击 Windows 下的图标
2. 推荐从 **gyan.dev** 下载：<https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-full.7z>
3. 解压后，将 `ffmpeg/bin` 文件夹路径添加到系统 PATH 环境变量中


## Apple Silicon

只支持 M 系列。Intel Mac 不跑 MLX。

1. 安装 Python 3.12 或 3.13（仓库要求仍是 `>=3.14`，但 MLX 若还没有 cp314 的 arm64 轮子，Mac 上先用有轮子的版本）。Mac 上的窗口是 Swift，不用再装 `python-tk`。再装 [ffmpeg](https://ffmpeg.org/download.html)，`brew install ffmpeg` 即可。
2. 在仓库根目录执行 `pip install -r requirements-macos.txt`。不要安装 `onnxruntime-directml`、`pywin32`、`keyboard`。
3. 把 MLX 权重放到 `models/mlx/`，目录名是 `SenseVoiceSmall`、`Fun-ASR-Nano-2512`、`Qwen3-ASR-1.7B-8bit`、`Qwen3-ASR-0.6B-8bit`、`Qwen3-ForcedAligner-0.6B-8bit`。缺目录时启动会写出目录名。需要下载时把 `config_server.py` 的 `mlx_auto_download` 设为 True，或调用 `core.server.engines.mlx.download.download_all`。
4. 系统设置里打开麦克风、辅助功能和输入监控。客户端发现没有辅助功能或输入监控时，会在主线程请系统把当前程序列进这两处，开关仍要自己打开。没有麦克风权限时会提示去系统设置，进程不退出。没有辅助功能权限时文字留在系统通知和终端里，不上屏。菜单栏和 Tk 不能开在同一个进程里，所以 Mac 上的提示不用 Tk 窗口。菜单栏状态项的固定名字是 CapsWriter。菜单栏装不下、系统把它排到屏幕外时，空档里会有同一个菜单的按钮。
5. 听写默认按住右 Option，超过 0.3 秒后开始录音，松开停止。pynput 会把这颗键报成 `alt_gr`，配置里写 `alt_r` 也会认。这个键按不住时，改 `config_client.py` 的 `darwin_shortcuts`，例如改成 `f8`，不要改回 CapsLock。
6. 本地编译运行 `./build-macos.sh`。脚本用本机 miniforge 的 `capswriter`（`/opt/homebrew/Caskroom/miniforge/base/envs/capswriter/bin/python3`）。这个环境要能 `import PyInstaller`。没有这个环境时才退回 `python3`，系统自带的那个不够。它调用 `python -m PyInstaller build.spec`，收集目录里留下 `start_client`、`start_server` 和 `batch_transcribe`，不再生成 `CapsWriter.app` 和 `CapsWriter Server.app`。只要打客户端，运行 `./build-macos.sh client`。`./clean-macos.sh` 只删除 `build` 和 `dist`；这三个程序还在运行时不删除，`models` 不动。直接运行 `start_client` 会带起 `start_server`，再开一次不会再加载模型。菜单栏由 `start_client` 提供。
